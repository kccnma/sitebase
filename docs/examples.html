SiteBase

SiteBase is a minimalistic HTML + CSS + JS base-level front-end starter for small, bespoke static websites. It was created for students learning the fundamentals of front-end web development. It can be used as a blank starter for custom websites, or as a hands-on learning experience by going through a series of lessons and exercises manually recoding it from scratch.
